Garda Agent Orchestrator

A local CLI that gives AI coding agents one governed path from task to done. I designed it and build it, and Garda is developed through Garda: its own task queue runs through the same gates.

Role
Author and maintainer
Stack
TypeScript, Node.js 24, npm package
Works with
Claude, Codex, Copilot, Gemini and other agents
Links
GitHub · Website · Demo

The problem

Coding agents are fast, but in a real repository they skip steps, lose context, avoid reviews and declare work done too early.

Asking them to be careful does not scale across agents, sessions and projects. The order of checks has to live outside the agent.

One path to done

Every task goes through the same gates in the same order. garda next-step prints the one command that is allowed next, so the order never depends on the agent remembering it.

Task lifecycle

  1. TODO
  2. →
  3. IN_PROGRESS
  4. →
  5. IN_REVIEW
  6. →
  7. DONE

Gates, in order

  1. enter-task-mode
  2. →
  3. load-rule-pack
  4. →
  5. preflight
  6. →
  7. compile
  8. →
  9. review-context
  10. →
  11. required reviews
  12. →
  13. doc-impact
  14. →
  15. completion

$ garda ui

Garda building Garda

A real task from Garda's own queue, open in garda ui. Each gate leaves an event: the stepper shows which stages passed, which one is running and what is still ahead. When this was captured the task was waiting for an independent reviewer, so it reads Blocked.

Decisions that matter

Completion is a gate, not a claim

A task becomes DONE only when the completion gate accepts the evidence: compile, required reviews and doc impact. The agent's own report does not count.

Reviews where the scope needs them

Specialist review lanes for code, database, security, API, tests, performance, infrastructure, refactoring and dependencies run when the change touches their area.

An audit trail you can check

Every step is a task event in a hash-chained log, and reviews leave artifacts. You can see what was checked, by whom and when.

Lean on tokens

Reviewers get compact context and scoped diffs, and gate output is filtered, so a green run stays short.

Configurable, not hard-coded

Profiles set the depth for a task, from fast to strict. Quality rules, review order, scope limits and protected controls all live in config and are visible in the UI.

Try it

Node.js 24 LTS or 22.13+ and Git. Open a terminal in the repository you want Garda to manage:

Then hand your coding agent the generated AGENT_INIT_PROMPT.md and pick a task from TASK.md.

$ npm install -g garda-agent-orchestrator
$ garda setup
$ garda ui
